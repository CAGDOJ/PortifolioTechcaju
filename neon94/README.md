# NEON94 — Portal Arcade

Portal de cinco jogos com fichas virtuais, login de visitante, catálogo e carteira demonstrativa. Não possui apostas ou transações com dinheiro.

Para habilitar cadastro real, crie um projeto Supabase EXCLUSIVO para NEON94, execute o schema de `supabase_schema.sql` incluído no pacote ZIP entregue na conversa e preencha `config.js` com URL e chave publicável. Habilite confirmação por e-mail e configure a Site URL do Supabase. Não insira chaves secretas no navegador.

PIX e criptomoedas não são suportados.
