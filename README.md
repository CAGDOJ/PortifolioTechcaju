# TechCaju — Portfólio de Carlos Oliveira Júnior

Site estático pessoal pronto para publicar no GitHub Pages.

## Publicar no GitHub Pages

1. Entre em https://github.com/CAGDOJ
2. Crie um repositório, por exemplo: `techcaju`
3. Envie todos os arquivos desta pasta para a raiz do repositório.
4. No GitHub, abra **Settings > Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)`.
7. Salve. Depois de alguns minutos, o site ficará disponível em algo como:
   `https://cagdoj.github.io/techcaju/`
